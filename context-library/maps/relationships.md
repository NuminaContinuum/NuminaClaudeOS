# Relationship map

**Last updated:** —

An overview of the people in your life, weighted by how often they appear in your entries and described by emotional valence.

Synthesised by `/maps` from individual files in `context-library/relationships/`. The detail lives there; this is the view.

---

*No relationships catalogued yet. People mentioned in journals, dreams, and journeys will be added automatically as you log entries. Run `/maps relationships` to refresh this overview once relationship files exist.*

---

## Format reference

When populated, this file groups people by role:

```markdown
## Family
- **Name** — N mentions — emotional valence. One-line of recurring theme.

## Friends
- **Name** — N mentions — valence. Theme.

## Teachers and guides
- **Name** — N mentions — valence. Theme.

## Inner figures
- **Name** — N mentions in dreams/journeys — valence. Theme.
```

Within each group, sorted by mention frequency descending.
