## Format reference

When populated, this file groups symbols by recency and trajectory:

```markdown
## Most frequent
- **Name** — N appearances since YYYY-MM-DD — relationship descriptor. Description.

## Recently emerged
- **Name** — N appearances since YYYY-MM-DD — descriptor. First appeared YYYY-MM-DD.

## Evolving
- **Name** — N appearances. Note on how the relationship has shifted.
```

Relationship descriptors: fear / attraction / projection / integration / embodiment.
