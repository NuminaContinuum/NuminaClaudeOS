# Memory Config — Numina OS

Memory root: `context-library/`
Host OS: Numina OS

## Promotion map

| Signal type | Promote to |
|---|---|
| Recurring pattern (3+ modalities) | `context-library/patterns/<slug>.md` |
| Adopted practice or intention | `context-library/commitments/<slug>.md` |
| Person or figure (waking or dream) | `context-library/relationships/<name>.md` |
| Recurring symbol or archetype | `context-library/archetypes/<name>.md` |
| Timeline milestone or turning point | `context-library/maps/timeline.md` |
| Anything without a clear home | `context-library/ingestion/adhoc/<slug>.md` |

## Pipeline folders (under memory root)

- `source/` — immutable verbatim copies of raw entries (never edited after creation)
- `ingestion/` — synthesis layer (themes, patterns, questions extracted by skills)
- `patterns/` — recurring inner patterns with evidence, user-confirmed
- `commitments/` — adopted practices and values-affirmed intentions
- `maintenance/` — /sweep reports

## Hook enforcement tiers

- **Hard block:** untagged evidence rows in `patterns/` and `commitments/` only
- **Soft warning:** provenance nudges for `archetypes/` and `relationships/`
- **No enforcement:** `journals/`, `dreams/`, `meditations/`, `journeys/` — never interrupt a session

## Notes

- Promotion is always judgment-gated and consent-based. The companion asks before promoting anything to patterns/ or commitments/.
- Recency is a weak signal. Old material can resurface and remain highly relevant.
- Dreams are symbolically tagged — a single dream does not promote a pattern. It adds evidence.
